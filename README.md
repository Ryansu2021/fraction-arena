# 分數森林・雙人雷射對戰

開啟 index.html 即可遊玩。首次載入需要網路，以取得 MathJax 3 公式引擎；音效由瀏覽器產生，不需音訊檔案。

- 左右兩位玩家各有 7 滴血，可同時點選答案。
- 三種難度、四種主題或全部混合。全部題目為亂數四選一。
- 答對扣對手 1 滴血，伴隨雷射、0.5 秒三次柔和閃光、花瓣與音效；答錯扣自己 1 滴血並顯示正解。
- 平板模式左側順時鐘 90°、右側逆時鐘 90°；小螢幕可在各自區域滑動查看內容。
- 電腦快捷鍵：左側 A/S/D/F，右側 J/K/L/;。
- 血量歸零即結束；再戰時重新分配不同小動物。
